# Burger-Point-Ordering-Sysyem

🍔 Usman Burger Point - Food Ordering System

*WELCOME TO USMAN BURGER POINT*
Ye mera Python me bana hua Burger Point ka Ordering Software hai. Is me pehle Menu dekho, phir Order karo, ye khud-ba-khud poora bill bana dega.

Developed by *Rana Abdul Wahab*

✨ Features
- 4 Options wala Menu: 1-Menu, 2-Order, 3-Helpline, 4-Exit
- 35+ Items pehle se Menu me saved hain
- Jo item Menu me na ho to kehta hai "Ye item menu me nahi hai"
- Quantity se Total khud calculate karta hai
- Aakhir me saaf-suthra Bill print karta hai
- Helpline Number bhi diya hua hai

🗂️ Menu Categories
- *BURGERS:* Zinger Burger 550, Zinger Cheese Burger 650, Chicken Burger 400, Beef Burger 500, Double Patty 750, Tower Burger 850, Mighty Zinger 900
- *SHAWARMA & SANDWICH:* Shawarma 350, Chicken Shawarma 380, Zinger Shawarma 420, Shawarma Platter 650, Club Sandwich 450
- *FRIES & SIDES:* Fries Small 150, Fries Large 250, Fries Loaded 400, Mayo Garlic Fries 300, Nuggets 6pc 450, Wings 6pc 550
- *PIZZA:* Pizza Small Chicken 700, Medium 1100, Large 1500, Fajita Small 750, Medium 1150, Large 1600
- *DRINKS & DESSERT:* Cold Drink Small 100, Large 180, Water 80, Ice Cream Scoop 150

🚀 Kaise Chalayen (How to Run)
1. Python install karein
2. File ko download karein usman_burger_point.py
3. Terminal / CMD me ye likhein: python usman_burger_point.py
